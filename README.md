# 📊 Functional Treat – Student Marks Analyzer

Welcome to **Functional Treat** 🎓✨

This is a simple Python program that analyzes students' marks and displays useful information such as total students, highest marks, lowest marks, average marks, pass/fail count, sorting, second highest/lowest marks, searching, and grade distribution.

---

## 🎯 Features

* 👨‍🎓 Counts the **total number of students**
* 🏆 Finds the **highest marks**
* 📉 Finds the **lowest marks**
* 📊 Calculates the **average marks**
* ✅ Counts **passed students**
* ❌ Counts **failed students**
* 📈 Calculates the **pass percentage**
* 🔢 Sorts marks in **ascending order**
* 🔽 Sorts marks in **descending order**
* 🥈 Finds the **second highest marks**
* 🥉 Finds the **second lowest marks**
* ✅ Checks whether **all students passed**
* ❌ Checks whether **any student failed**
* 🔍 Searches for a particular mark
* 🅰️ Displays **Grade A to Grade F distribution**

---

## 🛠️ Technologies Used

* 🐍 **Python**
* 📋 Python Lists
* 🔄 For Loop
* ❓ If-Else Statements
* 🧮 Built-in Functions

---

## 📚 Python Functions Used

| Function   | Purpose                       |
| ---------- | ----------------------------- |
| `len()`    | Finds total students          |
| `max()`    | Finds highest marks           |
| `min()`    | Finds lowest marks            |
| `sum()`    | Calculates total marks        |
| `count()`  | Counts a particular mark      |
| `sorted()` | Sorts the marks               |
| `all()`    | Checks if all students passed |
| `any()`    | Checks if any student failed  |

## 📊 Grade System

| Marks    | Grade |
| -------- | ----- |
| 90 – 100 | 🅰️ A |
| 80 – 89  | 🅱️ B |
| 70 – 79  | 🅲 C  |
| 60 – 69  | 🅳 D  |
| 40 – 59  | 🅴 E  |
| Below 40 | 🅵 F  |

## ▶️ How to Run

### 1️⃣ Install Python

Make sure Python is installed on your computer.

### 2️⃣ Save the Program

Save the file as:

```text
functional_treat.py
```

### 3️⃣ Run the Program

Open the terminal and type:

```bash
python functional_treat.py
```

## 🔍 Search Feature

At the end of the program, you can enter a mark to check whether it exists in the list.

Example:

```text
Enter a mark to search: 80
Mark exists in the list.
```

If the mark is not present:

```text
Enter a mark to search: 75
Mark does not exist in the list.
```
